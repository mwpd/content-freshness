Four small things, one question: is this post outdated?

Old tutorials keep ranking and getting shared long after they stop being right. A post counts as outdated when its last update is older than the limit you set.

For readers

A notice on the post

A one-line paragraph at the top of outdated single posts. Pages, archives and post lists are left alone. Style it with .mwpd-content-freshness-notice.

How to prune tomato plants

This post was last updated 3 years ago; some information may be out of date.

For editors

A “Last updated” column

In the Posts list, sortable, with outdated posts marked.

For editors

A weekly digest

Editors and Administrators each get an email with up to 20 of the stalest posts. When nothing is stale, nothing is sent.

[Field Notes] Posts that need a refresh
Building a raised bed from reclaimed timber5 years
How to prune tomato plants3 years
Choosing a rain barrel1 year
For site owners

One setting

Under Settings › Reading: after how many days a post counts as outdated. The default is 365.

Install, activate, done.

WordPress 6.0+PHP 7.4+No account or external service
1Download content-freshness.zip from the latest release.
2Upload it under Plugins › Add New › Upload Plugin and activate it.
3Optionally change the limit under Settings › Reading. The first digest goes out a week later.
# or with WP-CLI
$ wp plugin install content-freshness.zip --activate
Changing the noticeStyle .mwpd-content-freshness-notice, or copy any template from the plugin’s views/ into content-freshness/views/ in your theme.
No digest arriving?It’s sent by WP-Cron through wp_mail(). On quiet sites, add a real cron job; if no site email arrives, add an SMTP plugin.
Removing itDeactivating keeps your setting. Deleting removes it and the weekly event, the only two things the plugin stores.
How it is built

A simple plugin, built to show an approach.

Content Freshness is the worked example for the MWPD Basic Scaffold from Modern WordPress Plugin Development. The features are deliberately modest. They touch four different parts of WordPress, which makes them useful for showing how the scaffold keeps each part separate.

1

One feature, one service

The composition root lists the four services. None of them knows the others exist. The notice came first; each later feature was its own commit, adding a service and a line here without changing the ones before it.

2

Services say where and when, the scaffold does the rest

Each service implements small capability interfaces. A service that isn’t needed for a request is never constructed, and nothing branches on multisite: the scaffold visits each site for services that ask for it.

OutdatedPostNoticeSingle posts, once the query has runConditional · Delayed · Registerable
PostAgeColumnThe Posts list screen onlyConditional · Delayed · Registerable
FreshnessSettingAdmin requests; cleans up on uninstallDelayed · Registerable · SiteUninstallable
StaleContentDigestEvery request; schedules per siteRegisterable · SiteActivateable · SiteDeactivateable · SiteInitializable · SiteUninstallable
3

One rule, swappable

No feature reads the setting itself. They all ask a FreshnessPolicy interface. Bind your own class, for example to leave an evergreen category alone, and the notice, column and digest all follow it unchanged.

4

Rules a coding agent can follow

The architecture is written down and checked by tools, so a coding agent gets the same guidance as a person, and finds out right away when it strays.

AGENTS.mdThe repository map, the commands, the design principles in short, and the hard rules.
Failures that explainArchitecture rules run in the tests and in PHPStan. Every failure says what to do instead.
The need before the workaroundBefore reaching for a singleton or a global, an agent looks up the plugin’s way in docs/patterns.md.
No shortcuts to greenNo lowered analysis levels, baselines or deleted tests. Claims are verified against the source, not memory.

Working on it

Unit, integration, architecture and end-to-end tests, plus PHPCS, PHPStan (level max) and Psalm. CI runs them on PHP 7.4 and 8.3.

$ composer install && composer test && composer lint
$ npm ci && npm run e2e
